# DHCW Design System Components Reference

**Design System:** [DHCW Design System V2](https://www.figma.com/design/RplwUuFizhzeH1ng7M0SMO/DHCW-Design-System-V2)

This file documents all available components in the DHCW Design System. **Use this guide when creating user stories to ensure correct component usage.**

---

## 📋 How to Use This Guide

When writing acceptance criteria for UI stories:
1. Reference the appropriate component from this guide
2. Specify component variants (size, state, type)
3. Include accessibility requirements
4. Link to the DHCW Design System V2 reference in story details

**Component Reference Format:**
- **Component Name** — What it does
- **Variants** — Available sizes/states
- **Usage** — When to use (and when NOT to use)
- **Accessibility** — WCAG 2.1 AA requirements
- **Figma Link** — DHCW Design System V2 reference

## ✅ Component Validation Checklist

When reviewing acceptance criteria for UI stories, verify:

- [ ] All components used are from the 31 DHCW Design System V2 components listed above
- [ ] Component names match exactly with Figma component names
- [ ] Accessibility requirements are included in scenarios
- [ ] All form fields have associated labels
- [ ] Button types are used correctly (Primary vs Secondary)
- [ ] Select/Dropdown uses proper ARIA attributes
- [ ] Responsive behavior specified (mobile, tablet, desktop)
- [ ] Error states with messages defined
- [ ] Loading states defined
- [ ] Focus indicators mentioned

## 🔍 Component Selection Decision Tree

Use this to select the right component from DHCW Design System V2:

### "I need a clickable element..."
- Primary action? → **Buttons**
- Secondary action? → **Action Link** or **Buttons**
- Navigate back? → **Back Link**
- Breadcrumb trail? → **Breadcrumbs**
- Skip link? → **Skip Link**

### "I need to collect user input..."
- Text input? → **Text Input**
- Multi-line text? → **Textarea**
- Single selection? → **Radios**
- Multiple selections? → **Checkboxes**
- Many options? → **Select**
- Date/time? → **Date Input**
- File upload? → **File Upload**

### "I need to show multiple content sections..."
- Multiple pages of content? → **Pagination**
- Switchable content tabs? → **Tabs**
- Collapsible content? → **Details** or **Expander**
- Key-value summary? → **Summary List**
- Structured data? → **Table**

### "I need to communicate something to user..."
- Success/error/info message? → **Notification Banners**
- Critical message? → **Important Information**
- Form errors? → **Error Summary**
- Help text? → **Inset Text**
- Warning message? → **Warning Callouts** or **Warning Text**
- Session timeout? → **Time Out**

### "I need to organize content..."
- List of items? → **Cards** (grid layout)
- Grouped content? → **Panel**
- Related content? → **Details** or **Expander**
- Site structure? → **Site Navigation** or **Header/Footer**
